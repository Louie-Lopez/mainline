Privacy

Updated 21 October 2026

Mainline is a free, open-source project maintained by @Louie-Lopez. This page describes the local tool, this public demo, and support through GitHub Issues.

Your local project

Mainline stores the goal, stages, status labels, and any descriptions you or your AI agent record in local files. Its browser view reads those files through a service bound to 127.0.0.1 on your computer. It does not automatically capture conversations or upload project or conversation data to the maintainer. Mainline includes no usage analytics.

Local records remain until you remove them. You control their storage, sharing, backups, and removal. The maintainer has no central copy of these records.

Your AI application

The AI application you use with Mainline may read and process your conversation and project state to follow Mainline's instructions. Its privacy settings and policies apply independently. Mainline's local storage does not change how that application handles data.

This demo website

The demo uses sample data. It does not connect to your projects or local Mainline service. Its interactions run in your browser, without an account, upload form, analytics scripts, cookies, localStorage, or sessionStorage added by Mainline. The selected sample scenario and language can appear in the URL and browser history.

GitHub Pages hosts this site. GitHub may process technical request information, such as IP addresses, browser information, and access times, to provide its services. See the GitHub Privacy Statement for its practices.

Installation tools

If you choose a third-party installer, its own data practices apply. For example, the skills CLI sends installation telemetry by default; you can disable it with DISABLE_TELEMETRY=1. This is separate from Mainline. See the skills.sh privacy information and opt-out instructions.

Support and questions

GitHub Issues is the support channel. Issues, comments, and attachments are public, including the account information GitHub displays with them. The maintainer can read and respond to what you choose to share. Remove credentials, private project details, and personal information before posting. GitHub controls account data and platform retention under its own policy.

For a question about these practices, open an issue containing only information you are comfortable making public.

隐私说明

更新于 2026 年 10 月 21 日

Mainline 是由 @Louie-Lopez 维护的免费开源项目。本页说明本地工具、公开演示页和 GitHub Issues 支持渠道的数据处理方式。

本地项目数据

Mainline 将你或 AI Agent 记录的目标、阶段、状态标签和说明保存在本地文件中。网页通过绑定在本机 127.0.0.1 的服务读取这些文件。Mainline 不会自动收集对话，也不会向维护者上传项目或对话数据；工具内不含使用统计。

本地记录会保留到你将其移除为止，保存、分享、备份与移除由你控制。维护者没有这些记录的集中副本。

你使用的 AI 应用

配合 Mainline 使用的 AI 应用可能读取、处理对话和项目状态，以执行 Mainline 的说明。该应用自己的隐私设置与政策独立适用。Mainline 将状态保存在本地，不会改变 AI 应用本身的数据处理方式。

本演示网站

演示页使用示例数据，不连接你的项目或本地 Mainline 服务。交互在浏览器中完成；Mainline 没有为演示页添加账号、上传表单、统计脚本、Cookie、localStorage 或 sessionStorage。所选示例场景和语言可能出现在网址与浏览器历史中。

网站由 GitHub Pages 托管。GitHub 可能为提供服务处理 IP 地址、浏览器信息和访问时间等技术请求信息，具体见 GitHub 隐私声明。

安装工具

如果你选择第三方安装工具，其自身的数据处理规则独立适用。例如 skills CLI 默认发送安装统计，可通过 DISABLE_TELEMETRY=1 关闭。这与 Mainline 本身不同，详见 skills.sh 隐私说明与关闭统计的方法。

支持与咨询

支持渠道是 GitHub Issues。问题、评论和附件均公开，也包含 GitHub 随内容显示的账号信息。维护者可以阅读并回复你主动分享的内容。发布前请移除凭据、私人项目内容和个人信息。GitHub 账号数据及平台上的保留方式遵循 GitHub 自身政策。

如对本说明有疑问，可通过 Issue 联系，但请只填写你愿意公开的信息。
