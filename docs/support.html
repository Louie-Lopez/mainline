Support

Mainline keeps a project's goal, stable stages, and current work visible during long AI conversations. It is a free, open-source project maintained by @Louie-Lopez.

Ask for help or report a problem

Use GitHub Issues for questions, bug reports, and suggestions. English and Chinese are welcome. Check existing issues first; for a bug, include your operating system, AI application, Mainline version, what you expected, and what happened.

Issues are public. Remove credentials and private project or conversation content from examples and screenshots before posting.

Try it or install it

The interactive demo runs with sample data and needs no installation. To use Mainline with your own projects, follow the installation guide. The verified workflow is Codex on Windows; other environments may need testing.

Mainline is an independent project. It is not made by OpenAI and does not imply OpenAI endorsement.

支持

Issue 内容公开。发布示例或截图前，请移除凭据、私人项目和对话内容。
